사용자 관리

사용자 계정과 권한, 사용 여부를 관리합니다. 모든 변경은 서버 권한 검사를 통과해야 합니다.

비밀번호 초기화 규칙
  • 관리자는 기존 비밀번호를 조회하거나 직접 지정할 수 없으며 임시 비밀번호 초기화만 할 수 있습니다.
  • 임시 비밀번호는 16자리이며 영문 대문자·소문자·숫자·특수문자(!@#$%*-_)를 각각 포함합니다.
  • 초기화 즉시 해당 사용자의 기존 로그인 세션이 모두 종료되며, 임시 비밀번호는 결과 창에 한 번만 표시됩니다.
  • 본인 계정과 마지막 활성 관리자는 삭제할 수 없으며, 업무 이력이 연결된 사용자는 비활성화해야 합니다.
