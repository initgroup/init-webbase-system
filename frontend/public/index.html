SEVEN-STEP WORKFLOW

분석부터 운영까지 이어지는 7단계

자동 분석 결과를 바로 확정하지 않고, 전문가의 검토와 검증을 거쳐 운영에 반영합니다.

  1. 01
    DEFINE

    프로젝트·시나리오 정의

    업무 목적과 데이터 편집 시나리오를 하나의 프로젝트 단위로 관리합니다.

  2. 02
    INGEST

    데이터 수집·대상 선정

    CSV, TSV, 고정폭 텍스트, Excel과 Target DB 테이블을 확인하고 연결합니다.

  3. 03
    PROFILE

    컬럼 유형·관계 분석

    결측·중복·분포와 Cramer’s V, Pearson, Spearman, Eta Squared 관계를 분석합니다.

  4. 04
    DISCOVER

    설명 가능한 후보 규칙 발굴

    범주형은 IF/THEN 연관 규칙, 연속형은 중요 변수와 수식 규칙 후보를 제시합니다.

  5. 05
    DETECT

    규칙 위반 탐지·분석

    규칙별 위반 건수와 실제 행을 확인하고 분석 결과를 내보낼 수 있습니다.

  6. 06
    ORCHESTRATE

    시각적 Flow 자동화

    분석 단계를 DAG로 설계하고 같은 Run 결과와 데이터 계약을 연결해 재현성을 확보합니다.

  7. 07
    GOVERN

    전문가 검토·수정·운영 반영

    원본을 보존한 편집본에서 수정하고 검증된 DML만 운영에 반영하며 전체 이력을 남깁니다.
